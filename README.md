## 📌 Sobre o Projeto
Este projeto foi desenvolvido como parte do programa de iniciação em tecnologia. O objetivo é ajudar os usuários a estimarem o consumo mensal de energia elétrica de seus eletrodomésticos e o custo financeiro aproximado.

## 🧮 Fórmula Utilizada
O cálculo do consumo mensal em quilowatts-hora (kWh) segue a fórmula:

$$\text{Consumo Mensal (kWh)} = \frac{\text{Potência (W)} \times \text{Horas/Dia} \times 30}{1000}$$
